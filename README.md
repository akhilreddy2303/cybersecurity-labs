# Cybersecurity Labs

This repository contains hands-on labs and writeups aligned to SOC, IAM, cloud, and automation work.

## Suggested Learning Path (Recommended Order)
1. `siem/` – SIEM alerts, investigations, and incident response simulations  
2. `vulnerability-management/` – scanning, CVEs, remediation workflow  
3. `iam/` – RBAC, MFA, Azure AD/Okta auditing  
4. `cloud-security/` – AWS/Azure hardening, logging, CIS benchmarks  
5. `automation/` – scripts for log parsing and triage automation
