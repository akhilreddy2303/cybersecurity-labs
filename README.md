# Cybersecurity Labs

This repository contains hands-on cybersecurity labs aligned with SOC, IAM, cloud security, and automation work.

## Recommended Order
1. `siem/` – SIEM alerts, investigations, and incident response  
2. `vulnerability-management/` – scanning, CVEs, remediation workflow  
3. `iam/` – RBAC, MFA, and access audits  
4. `cloud-security/` – AWS/Azure hardening and logging  
5. `automation/` – scripts for SOC efficiency and automation
